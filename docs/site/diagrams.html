Use case mapping

Use-case diagram

Each role has a distinct set of things it can do in the platform.

CD

Candidate

Applies, takes tests, joins interview, and sees the final report.

RC

Recruiter

Creates jobs, reviews the pipeline, schedules interviews, and tracks analytics.

SR

Super recruiter

Manages recruiter access and handles platform-wide administration.

L1

Login / Sign up

Separate entry paths for candidate and recruiter accounts.

P1

Candidate profile

Edit resume-related data and keep the ATS score current.

J1

Browse jobs

Search, save, and apply for active job cards.

W1

Assessment flow

Aptitude, technical, coding, and interview stages with required flags.

R1

Review report

See the completed interview report and workflow summary.

A1

Create / edit jobs

Define title, description, salary, and stage configuration.

01

Candidate actions

Login, update profile, upload resume, scan ATS, apply, complete interview, and read the report.

02

Recruiter actions

Create jobs, toggle screening rules, monitor candidates, schedule interviews, and view analytics.

03

Super recruiter actions

Everything a recruiter can do, plus management of recruiter access and admin-level oversight.

Data movement

Data flow diagram

The application moves through authentication, profile/resume handling, assessment generation, interview, and reporting.

C

Candidate

Starts the flow by logging in and uploading a resume.

R

Recruiter

Creates jobs and reviews candidate progress.

A

AI services

Support ATS, question generation, and report analysis.

F

File store

Receives resumes, recordings, and snapshots.

1

Authentication

Token is created after login and attached to later API calls.

2

Profile + resume

Candidate profile data and resume uploads are stored and re-scanned.

3

Job posting

Recruiter enters the job details and assessment configuration.

4

Workflow engine

Builds the screening sequence, scores the rounds, and tracks completion.

5

Interview capture

Records camera, snapshot, transcript, and proctoring state.

DB

Database

Stores users, profiles, jobs, applications, interview reports, and analytics.

FS

Media storage

Stores uploaded files and interview assets under public URLs.

AI

Gemini analysis

Scans resumes, creates questions, and summarizes interview outcomes.

TTS

ElevenLabs speech

Speaks the interview prompt aloud in the live interview room.
