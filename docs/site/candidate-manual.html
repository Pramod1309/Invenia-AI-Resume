Step 1

Open the role selector and choose Candidate

The first screen asks the user to choose the correct portal.

Start here

What to do

Navigate to the live URL, wait for the splash screen, and select the Candidate card. This keeps the login path separate from the Recruiter portal and avoids confusion later in the journey.

  • Use the Candidate card when applying for jobs.
  • Use the Recruiter card only if you need to post or review jobs.
  • The selector page is also a good checkpoint for troubleshooting access problems.

Step 2

Sign in, or create a new candidate account

The login page keeps email and password only, so onboarding stays quick.

Onboarding

What to fill in

New users can sign up from this page. Existing users should enter the email and password they used during registration. After login, the system stores the token and opens the candidate dashboard.

Tip: If login fails, confirm that you chose the Candidate login path. The backend checks the user role as part of authentication.

Step 3

Complete the profile and upload a resume

The dashboard refreshes profile completion and ATS information after upload.

Profile

Profile setup

Add your name, current title, location, experience, skills, job preferences, and links. The profile view also shows the resume upload button and the live ATS scan area.

  • Keep the summary short and role-specific.
  • Use skills that match the jobs you want to apply for.
  • Upload a PDF, DOC, or DOCX resume before running ATS.

Best practice

Use the scan before applying

The score updates immediately after a resume upload or after the user presses the scan button. That means the candidate can improve the resume before starting the job application flow.

  • Review the ATS summary first.
  • Update the profile if the role needs extra skills or links.
  • Upload a newer resume if the file is outdated.

Step 4

Apply for a job and review the workflow

Each job card can be opened, saved, and applied from the jobs grid.

Assessment flow

What happens after Apply

The workflow preview shows which stages are required and which are optional. In the current build, aptitude, technical, and coding can be made optional by the recruiter, while the AI interview remains compulsory.

Good to know: The current job shown in the live data uses 5 aptitude questions, 5 technical questions, 2 coding prompts, and a 3-question AI interview.

Step 5

Read the completed report after the interview

The report is generated after the third answer is submitted.

Final state

What the report tells the candidate

Once the AI interview is finished, the backend calculates the final score and generates a report with strengths, gaps, recommendations, and a hiring decision summary.

  • Review the question-by-question feedback.
  • Check the proctoring summary and any warnings.
  • Use the final score to understand where you stand in the pipeline.

Candidate checklist

What to verify before handing the user back to hiring

Use this if you are helping candidates over the phone or in support chat.

Before applying

  • Profile completion is close to 100%.
  • Resume has been uploaded and scanned.
  • The ATS score is visible and understandable.

During the workflow

  • Optional tests can be skipped when the recruiter marks them optional.
  • The AI interview is always compulsory.
  • Voice capture should remain active while typing or speaking answers.

After completion

  • Review the final score and report.
  • Keep the submitted CV link for later reference.
  • Check the application history for the latest status.
